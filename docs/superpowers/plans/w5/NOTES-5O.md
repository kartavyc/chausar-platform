## Actual behavior and names

- Registration is `tender-desk`, with `bid-response`, `documentation-bucket` and `compliance-matrix`. The owner sets every price. The three source-executed baseline cases are gap-not-yes, iso-number-not-in-docs and pricing-left-to-owner.
- The public desk kind is `bid`, keyed by an existing order id. Its actions are import, reimport, answer, assign, controls, approve-type, ai-preview, ai-confirm and export. Mutations use the exact bid digest. Import takes `{rfpFileId, documentFileIds, issuerFileId, mapping}`. Spreadsheet mapping names sheet, questionColumn, answerColumn, firstRow and lastRow. The complete text of each issuer cell stays one question, including later pricing qualifiers.
- Current order identity and actual source bytes bind every answer. The RFP and its copies cannot be their own evidence. Sources from another client order are refused. Reading a source snapshots and rechecks records around asynchronous extraction.
- Code classifies first. Commercial provenance is sticky across owner reassignment. Every commercial answer is owner-written. Every question type has lengthWords and tone controls. Editing answers, controls or type invalidates exact approvals and AI previews.
- AI drafting is an explicit desk preview and confirmation path for one non-commercial question. The owner sees the exact question, controls and source documents before dispatch. Confirmation is consumed before the async model call. Both source changes and replaced questions invalidate completion. Private documents remain manual pending a qualified local model.
- Grounding checks factual claims and retrieval coverage against the client documents. A gap cannot be approved or exported. A gap draft cannot start with Yes. Today combines each bid's gaps into one request with ranked missing terms.
- Owner authorship does not exempt a commercial answer from factual grounding. Owner quotes therefore belong in the separate client evidence bucket. Explicit currency amounts have code receipts from exact minor-unit arithmetic, preserving source currency. Equal digits in another currency fail. The desk exposes moneyReceipts with questionId; export includes a price-receipts.json companion when amounts are present.
- Exports include DOCX with cover, XLSX and flat CSV. An issuer workbook fills only mapped answer cells; unrelated entry payloads, formulas, styles and sheets remain. Formula-like answer text is literal text. Protected, merged or formula target cells and unsupported archive profiles refuse explicitly. The ZIP container may be repacked; it is not claimed byte-identical.
- Forget follows explicit client, source, run and opaque call links. It removes source files and derived question records, stops linked runs and erases model payloads while retaining spend metadata. Reimport preserves opaque historical call ids and expires superseded previews, so it cannot orphan private payloads.
- The agent tools tender.questions and tender.ground read only the current run's client source bucket. They never approve, save answers, export or submit. Generic delivery copies a fixed handoff for the current approved desk pack. It cannot independently rewrite answers. Run entrance and model-confirmation boundaries check current sources before spend; final checks bind the current approved rows and exact handoff.
- The source and manual submission catalogue entries are tender-documents and tender-submission, with handwritten EN/HI guides. No portal credentials are accepted. The owner submits through GeM, CPPP, a state portal or mail.
