Implementation is in progress. This is not a package PASS or completion claim.

## Built so far

- `narration-studio/markup.ts`: strict voice, language, pause and reset markup; licensed stock voices; UTF-8 byte splitting; stored API request revision and explicitly unknown immutable provider model revision.
- `segments.ts`: A4 `scoreBack`, source/audio/transcript binding and owner listening approval. A retry verdict cannot be overridden. `tails.ts` proposes a conservative measured tail cut with a 250 ms margin.
- `state.ts` and `records.ts`: one body per segment, exact expiring quote binding, account-version binding and durable single-use attempt claim. An uncertain earlier call cannot be retried blindly.
- `source-core.ts` and `sources.ts`: TXT, Markdown and A5 DOCX reading; current order/client/actual-byte binding, narration licence scope/expiry, recheck after async extraction. No cloud-private permission is inferred.
- `provider.ts`: owner-only save/remove Google speech key, with no network test or secret in the result. A6 `speech-out.ts` now has dated Standard pricing and a 5000 UTF-8 byte refusal, with write readiness requiring key, price and implemented request/audio decoding.
- `master-core.ts`, `media-core.ts`, `media.ts`: actual desktop ffmpeg measurement and local whisper transcription of copied bytes; conservative mastering to new WAV, then measurement and transcription again. Timing is speech-interval precision, not invented word timing. Missing measurements do not pass.
- `explainer.ts`: every line must be an exact, ordered quoted source span; AI narration disclosure is carried with the result. Fetching/rendering is not yet integrated.

- YouTube: <https://support.google.com/youtube/answer/14328491>. Platform disclosure depends on realistic alteration; Chausar's stronger house requirement always discloses AI narration.
