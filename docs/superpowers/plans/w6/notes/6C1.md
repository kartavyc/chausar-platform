# 6C1: Connect your AI (D12)

## What was built

- The first screen after install is now "Connect your AI" (`app/ui/src/places/onboarding/ConnectAi.tsx`, from `reference-ui/Main.dc.html`): a top bar with the three setup steps, three tiles (ChatGPT plan through Codex, Claude plan through Claude Code, AI key), the plan-limits line and "Skip for now: use templates".
- Engine: `platform/runtime/venture/models/login.ts` (`LoginDesk`), held by the draft desk and stopped when the desk clears. Three new draft methods:
  - `venture.ai.tools {}` (read): each tool, whether it is found, and its sign-in state from its OWN status command (`codex login status`, `claude auth status`), matched against the same fixed phrases as `cli-status.ts` and then dropped.
  - `venture.ai.login.start { cli }` (approve, app only): starts the tool's own login as a child process (`codex login --device-auth`; `claude auth login`), argument array, no shell, the minimal `cliEnv` environment, an empty temp folder. A tool that already says it is signed in is never asked to sign in again. The output is parsed for the sign-in link (only `auth.openai.com`/`chatgpt.com` for Codex, `claude.ai`/`claude.com`/`console.anthropic.com` for Claude) and Codex's one-time code. Stopped on cancel, failure, a 15 minute timeout, or a desk clear.
  - `venture.ai.login.cancel { cli }`.
- Chausar never reads, copies or forwards a login file, token or password. Connecting a signed-in tool uses the existing `venture.ai.connect` with the preset's consent digest; the consent text sits under the button.
- The key path reuses the existing Your AI tile (draft desk, then the protected key storage when the business is kept).
- `auth.openai.com`, `claude.ai` and `claude.com` were added to `EXTERNAL_ORIGINS` in `contracts.ts` and `app/desktop/ipc-contract.cjs` so the desktop can open the sign-in page.
- Hosted keeps the old one-sentence first run (the draft desk is desktop only).
- Fake engine: `app/ui/src/engine/fake-first-run.ts` (a sample Codex installed and signed out; its device login prints a sample code and finishes after three looks; Claude Code not installed). `fake-business.ts` marks the codex preset connectable once the sample Codex is signed in, as the engine's CLI status does.
