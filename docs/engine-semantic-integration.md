# Engine semantic publication and consumer gate

`EngineSemanticService` is the concrete two-stage adapter between the installed connector runtime and `platform/semantic-qualification`. The host supplies the actual registry, clock, an explicit evidence lifetime, and authored dossiers. RPC callers cannot supply dossiers, qualification callbacks, grants or the ledger anchor.

Publication first checks complete trusted raw-read custody, current acquisition/reviewer authority, the pinned decoder, recipe and runtime dictionary, exact original byte hashes, snapshot and host freshness. After the importer has matched independent source totals, its synchronous `beforeInsert` hook runs real `qualifyCase` against the captured rows and rights-reviewed authored artifacts. Every declared measure must qualify. The runtime typed-fact projection must preserve the qualified event identity, date, net amount, tax, currency, company, branch, tax registration, quantity, unit and links. A refusal rolls back fact insertion and semantic evidence together.

The adapter executes every predeclared whole-company tuning and holdout case under the same semantic ontology and compiler. It records evidence, four actual evidence digests and a separate durable ledger/binding/proof anchor in the same publication draft. Renamed-field holdout cases use their own explicit compiled mapping. This public synthetic corpus demonstrates its authored cases; it does not establish learned mapping generalization, a sealed holdout or vendor qualification.

After publication, calculation, report, conversation, durable-job and saved-receipt consumers invoke `assertReady`. It checks the current compiler, rights/artifact dossier, source bytes and controls, actual published typed facts, exact required measure membership, active authority, source freshness, current connector evidence and independently retained anchor. It delegates the published snapshot/coverage check to `CursorImportService.assertReady(..., true)` and the semantic decision to the real `evaluateConnectorSemanticGate`. Decision timestamps come exclusively from the installed host clock; adapter DTO timestamps cannot select a historical decision time. Evidence expiry remains enforced on each use.

The supplied fixture has fourteen explicit source fields, independent literal net/tax/gross controls and per-row golden assertions. Its current two-row earned amount is `900719925474099400`; its separate company/template/configuration holdout has earned amount `1200`. Successful publication is labelled `synthetic-qualified`, with `liveVerified: false` and `writebackQualified: false`.

The current adapter refuses named vendors, sandbox/live semantic qualification, semantic exclusions, mixed-currency translation, fractional quantities and runtime definitions that do not preserve the qualified event-kind/net-money meaning. These paths need explicit supported mappings and independently qualified evidence before admission. No external connector, model, deployment or write-back is made qualified by these synthetic checks. Dedicated release security review remains blocked and unverified.
