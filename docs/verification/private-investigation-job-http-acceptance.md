# Private investigation job HTTP acceptance

The independent suite is `platform/tests/investigation-job-http.test.ts`. It uses paired loopback HTTP, the actual Engine and installed job/investigation adapters, and disposable encrypted experimental-file Vaults in the Windows temporary directory. It imports synthetic CSV facts and publishes owner-authored payment and invoice definitions. Literal expected minor-unit values are July collections `30000`, August collections `15000`, and August invoice value `70000`.

Each mandate declares its saved objective, source roots, remaining step identities, resource ceilings, spending reservation, stop rule, schedule, background permission, tested routes and allowed actions. The fixture explicitly enables autonomy and disables outbound model disclosure. Any attempted provider HTTP call fails the test.

The suite checks:

| Boundary | Independent evidence |
| --- | --- |
| Lost settlement and reopen | Real receipt and plan progress commit before a labelled host settlement failure; HTTP lock/open, readback and completion retain receipt IDs and one durable operation per step. |
| Completed prefix and distinct cuts | Existing prefix receipt remains unchanged; an uninterrupted plan at a separately authored knowledge cut returns the same literal measurements and preserves its own cut. Extra mandate sources cannot expand the saved branch scope. |
| Admission | Missing, reordered, duplicate and client-injected calculation steps, missing source roots and obsolete plan revisions refuse without a job or receipt. |
| Current authority | Other owners cannot read progress, execute or accept; revoked sessions and sources refuse. |
| Current evidence | Dictionary changes, source corrections and authored objective revisions fence obsolete jobs; acceptance rechecks delivered evidence. |
| Deletion | Source erasure removes dependent job, investigation, operation and receipt roots. |
| Budgets and cancellation | Pending work remains visible; known budget blocks reconcile as blocked, without a computation result, replay or deliverable. Cancellation creates no measurement. |
| Interpretation | Actual for/against receipt references remain attached to owner hypotheses with `not-established-cause`; no model call or causal qualification is asserted. |

Focused command:

```powershell
& 'C:\Program Files\nodejs\node.exe' --test --test-concurrency=1 --test-reporter=tap platform/tests/investigation-job-http.test.ts
```
