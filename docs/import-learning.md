# Learning from actual imports

`sources.import` now appends a canonical `LearningDecision` to the same transaction draft as its accepted import and complete fact lineage. Calling `sources.preview` records nothing. An identical accepted import returns its existing import without another accepted decision. Reconciliation or parser refusals record an admitted, bounded rejection without creating facts or a successful import row. Revoked/deleted sources and denied branches cannot create a refusal log.

The local record pins author ID, role and epoch; timestamp; explicit source and row roots; exact import or attempt ID, content hash, recipe hash, format and declared branches; and experimental qualification. `integrity` retains the input digest, while `recordIntegrity` protects the entire provenance envelope. Actual import decisions contain canonical field names/types and one enumerated reason, rather than source values, arbitrary headers, recipe names or error messages. A rejected attempt has no imported row lineage. Manual `learning.log` still retains its caller-authored details locally.

`learning.list`, preview and consent recheck current author and reader authority, source grants, the explicit import branches, retained rows/import identity and retention age. New previews bind the exact decision set and its full source/row union. Editing a preview's source list to empty does not bypass the original decisions. Old category logs and decisions without versioned provenance are hidden and refused for preview; their old input digest is not treated as proof of author or scope. Import admission remains per incoming row/recipe branch. Manual decisions retain their existing whole-source branch boundary.

The outbound `chausar.structure.v1` payload contains only existing enumerated event kinds, choices, reason codes, report shapes and allowlisted canonical field/type tokens. Money maps to the structural `decimal` type. Company/customer/entity IDs and names, amounts, dates, descriptions, source IDs, hashes, timestamps and free-form mapping values do not enter that payload. The local preview envelope retains private IDs for authorization and exact consent. Sharing stays off by default and Engine installs no export receiver. This does not upgrade experimental source qualification.

`appendLearningDecision(state, context, input, lineage?)` writes into a supplied transaction draft, avoiding nested Vault transactions. `assertLearningDecisionRecord(event)` validates historical shape and both integrity bindings independently of current original-author eligibility; the coordinator's source-deletion guard can use it without making revoked authors' content undeletable. Current read eligibility is checked separately. Learning decisions, previews, consent and export records carry top-level row/source roots for the existing recursive deletion and retention cleanup.

Focused evidence uses actual loopback HTTP, ImportService, LearningService, encrypted experimental Vault close/reopen and TrustService retention. It includes literal imported totals, exact structural payloads, duplicate/refused/empty imports, current source/author/branch checks, a queued revocation, provenance edits, legacy malformed logs, and source/row erasure. It performs no provider calls. Native database, GUI, receiver, vendor or security qualification is not claimed.

The refusal-only deletion acceptance depends on the coordinator-owned `trust.ts` join: baseline `sourceDeletionScope` recognizes only facts/imports and returns `SOURCE_NOT_FOUND` for a source represented solely by canonical rejection records. The acceptance test remains active to expose this dependency; no fake import row is created to satisfy it.
